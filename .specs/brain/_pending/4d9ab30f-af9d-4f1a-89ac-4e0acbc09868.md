Bun can retain the process's original `os.homedir()` after a test preload changes
`process.env.HOME`. Set the outer process environment before reproducing bugs in
older code that uses `os.homedir()`. For current channel code, the preload sets
`HITL_CHANNEL_HOME` per test and the filesystem guard checks the resolved path,
including symlink targets, against the temporary suite directory.

Verify isolation with a populated sentinel allowlist in the original home and
compare its contents and modification time before and after the full suite. Use
the preload's global `afterAll` hook to clean up temporary state after the suite.
[Bun lifecycle hooks](https://bun.com/docs/test/lifecycle)
